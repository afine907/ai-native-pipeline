# Agent 评估框架

## 核心问题

如何验证 Agent 修改后的效果是否变好？

## 评估维度

### 1. 功能正确性

Agent 是否完成了预期的任务？

```
测试方法：
- 准备 10-20 个典型任务
- 人工标注正确输出
- 对比 Agent 输出与正确答案
- 计算准确率
```

### 2. 输出质量

Agent 输出的质量如何？

| 维度 | 评估方法 |
|------|----------|
| 完整性 | 是否覆盖所有要求的内容？ |
| 准确性 | 信息是否正确？ |
| 简洁性 | 是否冗余？ |
| 可读性 | 是否易于理解？ |

### 3. 执行效率

Agent 执行任务的时间、成本？

```
指标：
- 执行时间（秒）
- Token 消耗
- 调用次数
```

### 4. 鲁棒性

Agent 是否能处理异常情况？

```
测试用例：
- 输入为空
- 输入格式错误
- 边界条件
- 冲突输入
```

## 评估方法

### 方法 1: 金标准对比（Gold Standard）

```python
# 评估脚本示例
test_cases = [
    {
        "input": "在用户模块增加手机号登录",
        "expected_output": {
            "core_files": ["src/auth/session.py", "src/auth/middleware.py"],
            "boundary": ["src/payments/"],
            "risks": ["authenticate() 被多处调用"]
        }
    },
    # ... 更多测试用例
]

def evaluate_agent(agent, test_cases):
    results = []
    for case in test_cases:
        output = agent.run(case["input"])
        score = compare_output(output, case["expected_output"])
        results.append(score)
    return sum(results) / len(results)
```

### 方法 2: LLM-as-Judge

用另一个 LLM 评估 Agent 输出：

```
Prompt:
你是一个评估专家。请评估以下 Agent 输出的质量。

任务：{input}
Agent 输出：{output}

请从以下维度打分（1-5分）：
1. 完整性：是否覆盖所有要求？
2. 准确性：信息是否正确？
3. 简洁性：是否冗余？
4. 可读性：是否易于理解？

总分：X/20
```

### 方法 3: 人工评估

最可靠但成本最高：

```
流程：
1. 准备评估界面
2. 展示 Agent 输出
3. 评估员打分
4. 统计结果
```

## 评估指标

### 核心指标

| 指标 | 计算方式 | 目标 |
|------|----------|------|
| **准确率** | 正确输出 / 总输出 | > 80% |
| **完整率** | 覆盖要求 / 总要求 | > 90% |
| **平均耗时** | 总时间 / 任务数 | < 60s |
| **Token 消耗** | 总 Token / 任务数 | < 10K |

### 质量分

```
质量分 = (完整性 * 0.3) + (准确性 * 0.4) + (简洁性 * 0.15) + (可读性 * 0.15)
目标：质量分 > 3.5/5
```

## 快速开始

### 最小评估集

如果时间有限，至少做这些：

1. **准备 5 个典型任务**
2. **运行 Agent，检查输出是否正确**
3. **记录执行时间**
4. **与之前的输出对比**

### 评估脚本

```bash
# 创建评估目录
mkdir -p .harness/eval

# 准备测试集
cat > .harness/eval/test_cases.json << 'EOF'
[
  {"id": 1, "input": "在用户模块增加手机号登录"},
  {"id": 2, "input": "将登录模块从 session 改为 JWT"},
  {"id": 3, "input": "添加商品列表分页功能"}
]
EOF

# 运行评估
python scripts/evaluate_agent.py --agent impact-analyzer --test-cases .harness/eval/test_cases.json

# 查看报告
cat .harness/eval/report.md
```

## 对比评估

修改 Agent 后，如何验证改进？

```
1. 保存修改前的评估结果
2. 修改 Agent
3. 运行相同的测试集
4. 对比结果

对比维度：
- 准确率是否提升？
- 质量分是否提升？
- Token 消耗是否减少？
- 执行时间是否缩短？
```

v2.0 版本在准确率、质量分、效率上都有提升，建议合并。
