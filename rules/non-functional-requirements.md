# 非功能需求

本文档定义PRD中非功能需求的标准分类和编写规范，确保生成的需求完整且可测试。

---

## 1. 非功能需求分类

| 类别 | 英文 | 说明 |
|------|------|------|
| 性能 | Performance | 响应时间、吞吐量、并发能力 |
| 安全 | Security | 认证授权、数据加密、安全审计 |
| 兼容性 | Compatibility | 浏览器、设备、系统的兼容性 |
| 可用性 | Usability | 易用性、辅助功能、本地化 |
| 可靠性 | Reliability | 稳定性、容错能力、恢复能力 |
| 可维护性 | Maintainability | 代码质量、监控、日志 |
| 可扩展性 | Scalability | 水平扩展、垂直扩展 |

---

## 2. 性能要求

### 2.1 响应时间

| 场景 | 目标值 | 说明 |
|------|--------|------|
| 页面首次加载 | ≤ 2秒 | 首屏渲染完成 |
| API请求 | ≤ 500ms | 95分位响应时间 |
| 复杂查询 | ≤ 2秒 | 列表、搜索等 |
| 文件上传 | ≤ 5秒 | 小文件（<5MB） |
| 页面切换 | ≤ 300ms | SPA路由切换 |

### 2.2 并发能力

| 指标 | 目标值 |
|------|--------|
| 支持在线用户 | ≥ 10000人 |
| API并发能力 | ≥ 500 QPS |
| 峰值并发 | ≥ 2000 QPS（持续5分钟） |

### 2.3 资源使用

| 指标 | 目标值 |
|------|--------|
| CPU使用率 | ≤ 70%（峰值） |
| 内存使用 | ≤ 80% |
| 磁盘使用 | ≤ 70% |

---

## 3. 安全要求

### 3.1 认证授权

| 项目 | 要求 |
|------|------|
| 密码存储 | 加密存储（bcrypt/salt） |
| 传输加密 | HTTPS全站加密 |
| Session管理 | 安全Cookie + HttpOnly |
| 密码策略 | 至少8位，含大小写+数字 |
| 登录失败限制 | 5次后锁定15分钟 |
| Token有效期 | AccessToken ≤ 2小时，RefreshToken ≤ 7天 |

### 3.2 数据安全

| 项目 | 要求 |
|------|------|
| 敏感数据 | 脱敏显示（手机号、身份证等） |
| 日志脱敏 | 密码、Token等不记录日志 |
| 数据传输 | 关键接口签名验证 |
| CSRF防护 | Token验证 |
| XSS防护 | 输入过滤 + 输出转义 |
| SQL注入 | 参数化查询 |

### 3.3 接口安全

| 项目 | 要求 |
|------|------|
| 频率限制 | 每IP每分钟 ≤ 60次 |
| 敏感操作 | 需要二次确认 |
| 文件上传 | 类型白名单 + 大小限制 |
| 第三方回调 | 签名验证 |

| 数字格式 | 千分位 |

## 6. 可靠性要求

### 6.1 可用性

| 指标 | 目标值 |
|------|--------|
| 服务可用率 | ≥ 99.9% |
| 年度停机时间 | ≤ 8.76小时 |
| 故障恢复时间 | ≤ 30分钟 |

### 6.2 容错能力

| 场景 | 要求 |
|------|------|
| 单点故障 | 不影响核心功能 |
| 服务降级 | 核心功能优先保障 |
| 数据一致性 | 最终一致性 |
| 缓存失效 | 自动降级到数据库 |

### 6.3 备份恢复

| 项目 | 要求 |
|------|------|
| 数据备份 | 每日全量 + 实时增量 |
| 备份保留 | ≥ 30天 |
| 恢复演练 | 季度一次 |
| RTO | ≤ 1小时 |
| RPO | ≤ 1小时 |

### 7.1 代码质量

| 指标 | 目标值 |
|------|--------|
| 代码覆盖率 | ≥ 80% |
| 圈复杂度 | ≤ 10 |
| 重复代码 | ≤ 5% |
| 文档完整性 | 核心模块有文档 |

### 7.2 监控告警

| 项目 | 要求 |
|------|------|
| 业务监控 | 关键指标实时监控 |
| 性能监控 | 响应时间、错误率 |
| 告警响应 | 5分钟内响应 |
| 日志级别 | ERROR及以上即时告警 |

```markdown
## 非功能需求

### 性能要求
- 页面首次加载 ≤ 2秒

- 移动端 iOS 14+ / Android 10+
- 响应式布局适配

### 可用性要求
- 键盘导航支持
- 颜色对比度 ≥ 4.5:1
- 支持屏幕阅读器

### 可靠性要求
- 服务可用率 ≥ 99.9%
- 故障恢复时间 ≤ 30分钟
- 数据备份每日一次

### 可维护性要求
- 代码覆盖率 ≥ 80%
- 关键模块有文档
- 监控告警覆盖核心指标
```

## 9. 检查清单

编写非功能需求时，必须检查：

- [ ] 性能指标具体可测量
- [ ] 安全措施覆盖常见威胁
- [ ] 兼容版本明确
- [ ] 辅助功能有考虑
- [ ] 备份恢复策略明确
- [ ] 与业务规模匹配
