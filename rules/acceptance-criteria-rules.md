# 验收标准编写规范

本文档定义验收标准的编写规范，确保生成的验收条件可测试、可验证。

---

## 1. 验收标准原则

### 1.1 SMART原则

| 原则 | 说明 | 示例 |
|------|------|------|
| Specific（具体） | 明确描述期望结果 | "显示用户头像" 而非 "显示用户信息" |
| Measurable（可衡量） | 可以量化或验证 | "响应时间<200ms" 而非 "响应快" |
| Achievable（可实现） | 技术上可行 | 基于现有技术栈评估 |
| Relevant（相关） | 与业务目标相关 | 聚焦用户价值 |
| Time-bound（有时限） | 可在合理时间内验证 | 单次操作可完成验证 |

### 1.2 验收条件类型

| 类型 | 说明 | 示例 |
|------|------|------|
| 功能验证 | 验证功能正常工作 | 登录成功跳转首页 |
| 边界验证 | 验证边界条件处理 | 空密码提示必填 |
| 异常验证 | 验证异常情况处理 | 网络断开显示重试 |
| 性能验证 | 验证性能指标 | 页面加载<1s |
| 安全验证 | 验证安全机制 | 未登录无法访问 |

## 2. 验收标准格式

### 2.1 检查清单格式

```markdown
## 验收标准

### 功能验证
- [ ] 预期行为描述

### 边界验证
- [ ] 边界条件描述

### 异常验证
- [ ] 异常场景描述
```

### 2.2 Given-When-Then格式

```markdown
## 验收标准

### 场景：正常流程
- **Given**: 前置条件
- **When**: 触发操作
- **Then**: 预期结果

### 场景：异常流程
- **Given**: 异常条件
- **When**: 触发操作
- **Then**: 预期响应
```

## 3. 验收条件分类

### 3.1 功能验收

```markdown
### 功能：用户登录

正常流程
- [ ] 输入正确的用户名和密码，点击登录，成功跳转首页
- [ ] 登录成功后，页面显示用户昵称
- [ ] 登录成功后，保存登录态，刷新页面保持登录

错误处理
- [ ] 用户名为空，提示"请输入用户名"
- [ ] 密码为空，提示"请输入密码"
- [ ] 用户名不存在，提示"用户不存在"
- [ ] 密码错误，提示"密码错误"
- [ ] 连续输错5次，锁定账号30分钟
```

### 3.2 界面验收

```markdown
### 界面：登录页

布局
- [ ] 登录框居中显示
- [ ] 输入框高度为48px
- [ ] 按钮宽度为100%
- [ ] 移动端自适应布局

样式
- [ ] 主色调符合品牌色#1890ff
- [ ] 字体大小16px
- [ ] 输入框placeholder颜色#999
- [ ] 登录按钮hover状态变深

交互
- [ ] 输入框获取焦点显示边框高亮
- [ ] 输入错误时输入框变红
- [ ] 点击登录按钮显示loading态
```

### 3.3 数据验收

```markdown
### 数据：用户信息

字段验证
- [ ] 用户名显示正确
- [ ] 邮箱显示正确（脱敏显示如 a***@example.com）
- [ ] 手机号显示正确（脱敏显示如 138****8888）
- [ ] 头像显示正确，头像不存在显示默认头像

数据格式
- [ ] 日期格式为 YYYY-MM-DD
- [ ] 金额显示格式为 ¥1,234.56
- [ ] 列表按创建时间倒序排列
```

## 4. 边界条件清单

### 4.1 输入边界

| 场景 | 边界值 | 预期 |
|------|--------|------|
| 字符串长度 | 最小/最大 | 提示长度限制 |
| 数字范围 | 最小/最大 | 提示超出范围 |
| 文件大小 | 最大值 | 提示文件过大 |
| 图片尺寸 | 最小/最大 | 提示尺寸不符 |
| 批量数量 | 最大值 | 提示超出上限 |

### 4.2 状态边界

| 场景 | 边界值 | 预期 |
|------|--------|------|
| 空数据 | 无数据 | 显示空状态 |
| 单条数据 | 仅1条 | 正常显示 |
| 大量数据 | >1000条 | 分页或虚拟滚动 |
| 超长文本 | >10000字 | 截断或展开 |

### 4.3 网络边界

| 场景 | 边界值 | 预期 |
|------|--------|------|
| 无网络 | 离线 | 提示网络异常 |
| 网络慢 | >10s | 显示加载超时 |
| 请求超时 | >30s | 自动断开 |
| 服务端错误 | 5xx | 提示服务异常 |

## 5. 验收标准示例

### 示例：订单创建功能

```markdown
# 验收标准：订单创建

## 功能验收

### 正常流程
- [ ] 用户选择商品并点击"立即购买"，进入确认订单页
- [ ] 订单页显示商品信息（名称、规格、数量、价格）
- [ ] 用户填写收货地址并选择支付方式
- [ ] 点击"提交订单"，创建成功并跳转支付页
- [ ] 订单创建成功后，库存相应减少

### 地址选择
- [ ] 显示已保存的地址列表
- [ ] 选择已有地址，自动填充表单
- [ ] 可新增收货地址
- [ ] 地址表单包含：姓名、手机号、省市区、详细地址

### 支付方式
- [ ] 显示可用的支付方式（微信、支付宝、银行卡）
- [ ] 选择支付方式后，显示对应支付按钮

## 界面验收

### 布局
- [ ] 订单确认页布局符合设计稿
- [ ] 商品列表、商品详情、底部操作栏布局正确
- [ ] 移动端自适应，触摸区域≥44px

### 交互
- [ ] 地址选择弹窗滑动流畅
- [ ] 支付方式切换无闪烁
- [ ] 提交订单按钮点击反馈明显

## 数据验收

### 订单数据
- [ ] 订单号唯一且自动生成
- [ ] 订单金额计算正确（商品总价 + 运费 - 优惠）
- [ ] 订单创建时间正确

### 金额计算
- [ ] 商品总价 = 单价 × 数量
- [ ] 实付金额 = 商品总价 + 运费 - 优惠
- [ ] 显示原始价格和优惠后价格

## 异常验收

### 前置条件异常
- [ ] 库存不足，提示"库存不足"并返回
- [ ] 商品已下架，提示"商品已下架"并返回
- [ ] 用户未登录，提示"请先登录"并跳转登录页

### 提交异常
- [ ] 地址信息不完整，提示补充
- [ ] 未选择支付方式，提示选择
- [ ] 支付失败，提示"支付失败，请重试"
- [ ] 网络异常，提示"网络异常，请检查网络"

## 性能验收

- [ ] 页面首次加载 < 1秒
- [ ] 订单提交响应 < 2秒
- [ ] 动画流畅，无卡顿

## 安全验收

- [ ] 未登录用户无法提交订单
- [ ] 订单金额由服务端计算，防止篡改
- [ ] 敏感数据脱敏显示
```

## 6. 验收标准检查清单

编写验收标准时，必须检查：

- [ ] 每个验收条件都是可测试的
- [ ] 正常场景和异常场景都有覆盖
- [ ] 边界条件已考虑
- [ ] 界面和数据都有验证
- [ ] 验收条件描述清晰，无歧义
- [ ] 验收条件可自动化执行（可选）
